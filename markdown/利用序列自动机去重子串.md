# 利用序列自动机去重子串

如何快速输出一个字符串指定区间内的去重子串？

需要运用到序列自动机中的**nxt**数组

由于字符串全部为小写英文字母，所以无论区间有多长，去重后的子串**最多只有 26 个字符**。因此，我们完全不需要从左到右遍历整个区间。

我们只需要对于查询区间 $[L, R]$，快速知道**哪些字母出现了，以及它们第一次出现的位置**。

根据这些字母第一次出现的位置进行排序，就能直接得到“去重后的子串”。

**具体做法：预处理“下一个字符”的位置 (Next 数组)**

1. 我们可以创建一个二维数组 `nxt[i][c]`，表示从字符串第 `i` 个位置开始（包含 `i`），字符 `c` **第一次出现的位置**。
2. 这个数组可以从后往前遍历字符串，用 $O(26 \times |S|)$ 的时间提前预处理好。
3. 到了查询阶段，对于给定的区间 $[L, R]$，我们直接遍历 26 个字母：如果 `nxt[L][c] <= R`，说明字母 `c` 在这个区间内出现了，并且它在去重子串中的相对顺序取决于它的坐标 `nxt[L][c]`。
4. 把区间内出现的字母按 `nxt` 坐标排个序，就能在 $O(26 \log 26)$ 的极快时间内还原出去重后的子串，然后直接对比即可。

## 例题

## P12838 [蓝桥杯 2025 国 B] 子串去重

## 题目描述

给定一个字符串 $S$ 以及若干组询问，每个询问包含两个区间 $(L_a, R_a)$, $(L_b, R_b)$，你需要判定 $S_{L_a}, S_{L_a+1}, \ldots, S_{R_a}$ 与 $S_{L_b}, S_{L_b+1}, \ldots, S_{R_b}$ 去重后有多少个位置上的字符是不同的。

这里的去重指的是每个子串对于每种字符，只保留第一个出现的那个，后续出现的直接丢弃。

例如 $\tt{aabcbac}$ 在选中区间 $[1,5]$ 时，得到子串 $\tt{aabcb}$，去重后为 $\tt{abc}$，选中区间 $[3,6]$ 时得到 $\tt{bcba}$，去重后为 $\tt{bca}$。

特别地，两个长度不同的子串中，较长串的多出的部分每个位置都视为不同。

## 输入格式

输入第一行包含一个字符串 $S$。

第二行包含一个整数 $m$，表示询问次数。

接下来 $m$ 行，每行包含四个整数，表示一次询问。

## 输出格式

输出共 $m$ 行，每行一个整数对应每次询问的答案。

## 输入输出样例 #1

### 输入 #1

```
aabcbabacdab
3
1 1 2 2
1 10 6 9
4 7 9 12
```

### 输出 #1

```
0
1
2
```

## 说明/提示

**【评测用例规模与约定】**

对于 $40\%$ 的评测用例，$|S| \leq 10$, $m = 1$。

对于 $60\%$ 的评测用例，$|S|, m \leq 5000$。

对于 $100\%$ 的评测用例，$1 \leq |S|, m \leq 10^5$, $1 \leq L_a \leq R_a \leq |S|$, $1 \leq L_b \leq R_b \leq |S|$。

## 题解

```c++
#include<bits/stdc++.h>
using namespace std;
const int N = 1e5+3;
string s;
int nex[N][26];
int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    cin >> s;
    int n = s.size();
    int T;
    cin >> T;
    for(int i = 0; i < 26; i++){
        nex[n+1][i] = n+1;
    }

    for(int i = n; i >= 1; i--){
        for(int j = 0; j < 26; j++){
            nex[i][j] = nex[i+1][j];
        }
        nex[i][s[i-1] - 'a'] = i;
    }

    while(T--){
        int la, ra, lb, rb;
        cin >> la >> ra >> lb >> rb;
        vector<int> c1;
        vector<int> c2;
        for(int i = 0; i < 26; i++){
            if(nex[la][i] <= ra) c1.push_back(nex[la][i] - 1);
            if(nex[lb][i] <= rb) c2.push_back(nex[lb][i] - 1);
        }
        sort(c1.begin(), c1.end());
        sort(c2.begin(), c2.end());
        int len1 = c1.size();
        int len2 = c2.size();
        int cnt = abs(len1 - len2);
        int up = min(len1, len2);
        for(int i = 0; i < up; i++){
            if(s[c1[i]] != s[c2[i]]) cnt++;
        }
        cout << cnt;
        if(T) cout << "\n";
    }

    return 0;
}
```

## 核心代码

### 1. 初始化nex数组

```c++
for(int i = 0; i < 26; i++){
        nex[n+1][i] = n+1;
    }// 一共n个字符，初始化边界，用 n+1 表示未找到
	// 从后往前推导，构建 nex 数组
    for(int i = n; i >= 1; i--){
        for(int j = 0; j < 26; j++){
            //出了当前位置本身字母以外，其余所有字母的第一次出现的位置同 i+1
            nex[i][j] = nex[i+1][j];
        }
        // 修正当前位置的字符出现的位置，其第一次出现的位置就是它自己
        nex[i][s[i-1] - 'a'] = i;
    }
```

### 2. 查询

```c++
// 2. 处理每次查询
    while (m--) {
        int La, Ra, Lb, Rb;
        cin >> La >> Ra >> Lb >> Rb;
		//记录两个子串出现的字符以及位置
        vector<pair<int, char>> seqA, seqB;

        // 查找区间 A [La, Ra] 中包含哪些字符，以及它们第一次出现的位置
        for (int c = 0; c < 26; ++c) {
            // 如果当前字符首次出现位置<=右区间，说明在该区间内包含这个字符
            if (nxt[La][c] <= Ra) {
                //记录该字符的位置和具体字符
                seqA.push_back({nxt[La][c], c + 'a'});
            }
        }
        
        // 查找区间 B [Lb, Rb] 中包含哪些字符，以及它们第一次出现的位置
        for (int c = 0; c < 26; ++c) {
            if (nxt[Lb][c] <= Rb) {
                seqB.push_back({nxt[Lb][c], c + 'a'});
            }
        }

        // 按照第一次出现的位置坐标排序，还原去重后的子串字符顺序
        sort(seqA.begin(), seqA.end());
        sort(seqB.begin(), seqB.end());
```
