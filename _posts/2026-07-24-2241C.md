# 2241C RemovevomeR

- 平台：Codeforces
- 题目：[2241C RemovevomeR](https://codeforces.com/problemset/problem/2241/C)
- 来源：2026-07-24-2306-算法-2241C-RemovevomeR（capture_id：`2026-07-24-230623`）
- 每日总结：2026-07-24
- 算法类型：字符串题目索引、分类讨论题目索引
- 相关专题：二进制字符串的段数与回文删除

## 2. 题目大意

给定一个二进制字符串。每次可以选择长度至少为 $2$ 的回文子串，并从中删除恰好一个字符。求经过任意次操作后字符串的最小可能长度。

## 3. 思路

令 $c$ 为相邻字符不同的位置数量，它等于连续相同字符段数减一。

- $c=0$：整个字符串只有一个字符段，可以不断在相同字符组成的回文子串中删除，答案为 $1$。
- $c=1$：字符串恰好由两个不同字符段组成。跨越唯一边界的子串首尾字符不同，不可能是回文串；每一段最多各压缩为一个字符，最后剩下 `01` 或 `10`，答案为 $2$。
- $c\ge2$：字符串至少有三个字符段。二进制字符段必然出现 $A\ldots AB\ldots BA\ldots A$ 的结构，可利用首尾相同的回文子串逐步消去中间段并合并同字符段；交替串也可以反复选择长度为 $3$ 的回文子串缩短。最终可以只剩同一种字符，再继续删到长度 $1$。

因此当且仅当 $c=1$ 时答案为 $2$，其他情况答案为 $1$。详见 二进制字符串的段数与回文删除。

时间复杂度为 $O(n)$，额外空间复杂度为 $O(1)$。

## 4. Code

以下代码已通过题目样例，并穷举核对了所有长度不超过 $7$ 的二进制字符串；未据此声称平台 AC。

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    string s;
    cin >> n >> s;

    int changes = 0;
    for (int i = 0; i + 1 < n; ++i) {
        changes += (s[i] != s[i + 1]);
    }

    cout << (changes == 1 ? 2 : 1) << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) solve();
    return 0;
}
```
