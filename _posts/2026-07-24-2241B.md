# 2241B Good times Good times

## 2. 题目大意

一个十进制整数若至多包含两种不同数字，就称为好数。给定一个好数 $x$，构造 $2\le y\le10^9$，使 $y$ 与 $x\times y$ 都是好数。

## 3. 思路

设 $x$ 的十进制位数为 $k$，构造

$$
y=10^k+1.
$$

$y$ 只含数字 `0` 和 `1`，因此它是好数。同时

$$
x\times y=x\times10^k+x,
$$

这正是把两个 $x$ 的十进制表示拼接起来，见 十进制整数拼接。由于 $x$ 本身至多包含两种不同数字，拼接后的乘积仍至多包含这两种数字。

题目保证 $x<10^8$，所以 $k\le8$，最大构造为 $10^8+1\le10^9$，始终满足范围限制。

每个测试用例的时间复杂度为 $O(\log x)$，额外空间复杂度为 $O(1)$。

## 4. Code

以下代码已通过题目样例；未据此声称平台 AC。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

void solve() {
    ll x;
    cin >> x;

    int digits = 0;
    for (ll value = x; value > 0; value /= 10) {
        ++digits;
    }

    ll power = 1;
    while (digits--) power *= 10;
    cout << power + 1 << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) solve();
    return 0;
}
```
