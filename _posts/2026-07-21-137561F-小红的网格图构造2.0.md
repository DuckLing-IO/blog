## 2. 题目大意

构造一个 $n$ 行 $m$ 列的 01 网格，使任意 $2\times2$ 区域都同时包含 `0` 和 `1`，并使整个网格恰好包含 $k$ 个 `1`。若无法构造，输出 `No`；否则输出 `Yes` 和任意一种合法网格。

## 3. 思路

可以选出

$$
limit=\left\lfloor\frac n2\right\rfloor\left\lfloor\frac m2\right\rfloor
$$

个互不重叠的 $2\times2$ 区域。每个区域至少需要一个 `1` 和一个 `0`，因此有解条件为

$$
limit\le k\le nm-limit.
$$

令 $target=\min(k,nm-k)$。把 1-based 偶数行固定为 `010101...`，其余位置先填 `0`。基础网格恰有 $limit$ 个 `1`，而且任意 $2\times2$ 都能从偶数行的两个相邻格子中同时看到 `0` 和 `1`，所以奇数行可以任意填充。再在奇数行中补入 $target-limit$ 个 `1`。

若 $target=nm-k$，最后把整个网格的 `0`、`1` 取反，合法性不变，`1` 的数量变为 $k$。

时间复杂度和空间复杂度均为 $O(nm)$。

## 4. Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, k;
    cin >> n >> m >> k;

    int total = n * m;
    int limit = (n / 2) * (m / 2);
    if (k < limit || k > total - limit) {
        cout << "No\n";
        return 0;
    }

    bool invert = k > total - k;
    int target = min(k, total - k);
    vector<string> grid(n, string(m, '0'));

    for (int i = 1; i < n; i += 2) {
        for (int j = 1; j < m; j += 2) grid[i][j] = '1';
    }

    int need = target - limit;
    for (int i = 0; i < n && need > 0; i += 2) {
        for (int j = 0; j < m && need > 0; ++j) {
            grid[i][j] = '1';
            --need;
        }
    }

    if (invert) {
        for (auto &row : grid) {
            for (char &cell : row) cell = (cell == '0' ? '1' : '0');
        }
    }

    cout << "Yes\n";
    for (const string &row : grid) cout << row << '\n';
    return 0;
}
```
