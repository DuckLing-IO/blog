## 2. 题目大意

给定两个长度为 $n$ 的 01 字符串 $s,t$，二者包含的 `1` 数量相同。字符 $c$ 初始为 `2`，每次可以选择 $s$ 的一个位置并交换该字符与 $c$。要求在不超过 $2n$ 次操作内使 $s=t$，并输出任意一种方案。

## 3. 思路

把错位位置分为两类：$s_i=0,t_i=1$ 的位置记入 $a$，$s_i=1,t_i=0$ 的位置记入 $b$。因为 $s,t$ 中 `1` 的数量相同，所以两类位置的数量相同。

对于每一对 $(a_i,b_i)$，依次操作 $a_i,b_i,a_i$。三次操作后，这两个位置都变成目标字符，$c$ 也恢复为 `2`。若每类错位位置有 $q$ 个，共需 $3q$ 次操作；由于 $2q\le n$，所以 $3q\le\frac{3n}{2}<2n$。

时间复杂度为 $O(n)$，额外空间复杂度为 $O(n)$。

## 4. Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    string s, t;
    cin >> n >> s >> t;

    vector<int> zeroToOne, oneToZero;
    for (int i = 0; i < n; ++i) {
        if (s[i] == t[i]) continue;
        if (s[i] == '0') zeroToOne.push_back(i + 1);
        else oneToZero.push_back(i + 1);
    }

    cout << 3 * zeroToOne.size() << '\n';
    for (int i = 0; i < static_cast<int>(zeroToOne.size()); ++i) {
        cout << zeroToOne[i] << '\n'
             << oneToZero[i] << '\n'
             << zeroToOne[i] << '\n';
    }
    return 0;
}
```
