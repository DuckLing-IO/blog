## 题目描述

小蓝特别喜欢偶数，当他看到字符串时，他总是要检查一下是不是每种字符都是出现偶数次。给定一个字符串，请帮助小蓝检查一下该字符串是否满足要求。

## 输入格式

输入一行包含一个字符串，由小写英文字母组成。

## 输出格式

如果字符串中的每种字符都是出现偶数次，输出大写英文单词 $\tt{YES}$，否则输出大写英文单词 $\tt{NO}$。

## 输入输出样例 #1

### 输入 #1

```
banana
```

### 输出 #1

```
NO
```

## 输入输出样例 #2

### 输入 #2

```
bbnana
```

### 输出 #2

```
YES
```

## 说明/提示

### 评测用例规模与约定

- 对于 $50\%$ 的评测用例， $1 \leq$ 字符串长度 $\leq 1000$；
- 对于所有评测用例，$1 \leq$ 字符串长度 $\leq 10^{6}$。

---

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
ll a[5000];
int main(){
	ios::sync_with_stdio(0);
	cin.tie(0);
	char c;
	vector<bool> fl(26,0);
	while(cin >> c){
		int idx = c - 'a';
		fl[idx] = 1-fl[idx];
	}
	bool b = 1;
	for(bool a : fl){
		if(a){
			b = 0;
			break;
		}
	}
	if(b) cout << "YES";
	else cout << "NO";
	return 0;
}
```
