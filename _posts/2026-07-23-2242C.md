# 2242C Unstable Elements

- 算法类型：不变量题目索引、枚举题目索引、模运算题目索引
- 相关专题：同步增减组的分段可达性

## 2. 题目大意

给定一个非递减整数数组。每次操作都会标记第一个元素以及所有与左侧元素不同的元素，即每个连续相同段的第一个元素；随后只能统一删除所有被标记元素，或统一复制所有被标记元素。

等价地，把数组按数值分为 $m$ 个连续组，组大小为

$$
c_1,c_2,\ldots,c_m.
$$

一次操作会让每个仍存在的组大小同时加 $1$ 或减 $1$；大小减到 $0$ 的组永久消失。求经过任意次操作后，长度恰好为 $k$ 的不同可达数组数量。

约束为 $1\le n,k\le3\times10^5$，所有测试用例的 $n$ 之和不超过 $3\times10^5$。

## 3. 思路

具体数值只决定各组在数组中的身份，操作过程只与组大小有关。用有序映射记录

```text
mp[x] = 初始大小为 x 的组数
```

并维护：

- `gp`：当前仍存在的组数；
- `cn`：当前这些组的初始大小之和。

只要存活组集合不变，每个组都经历相同的净增减次数 $x$，因此各组大小相对初始值的差相同，数组长度为

$$
L=cn+x\cdot gp.
$$

所以目标长度必须满足

$$
k\equiv cn\pmod{gp}.
$$

按初始组大小从小到大枚举。设当前最小组大小为 `key`，为了让它仍然存在，需要

$$
key+x\ge1,
$$

即 $x\ge-(key-1)$。当前阶段可达到的最小长度为

$$
mi=cn-(key-1)\cdot gp.
$$

因此本阶段存在一个长度为 $k$ 的可达数组，当且仅当

```cpp
k >= mi && (k - cn) % gp == 0
```

对于固定的存活组集合与目标长度，$x$ 唯一，因此本阶段至多贡献一个答案。

处理完 `key` 后，所有初始大小为 `key` 的组会在继续删除时最先消失。若这样的组有 `val` 个，则进入下一阶段前更新：

```cpp
cn -= key * val;
gp -= val;
```

不同阶段的存活数值集合不同，所以对应数组不会重复统计。这个分段过程详见 同步增减组的分段可达性，其中的整除判断基于 同余关系。

统计连续组需要 $O(n)$，有序映射的插入与遍历总计 $O(n\log n)$，空间复杂度为 $O(n)$。由于当前阶段满足 $key\cdot gp\le cn\le n$，长度计算不会超出 32 位有符号整数范围。

## 4. Code

以下代码未在平台验证；已在本地以 C++17 编译并通过题目样例，核心逻辑还通过 780 组小规模组长组合、目标长度 $1\sim12$ 的穷举对拍。

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n, k;
    cin >> n >> k;

    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }

    map<int, int> mp;
    int gp = 0;
    int size = 1;

    for (int i = 1; i <= n; ++i) {
        if (i + 1 <= n && a[i] == a[i + 1]) {
            ++size;
        } else {
            ++mp[size];
            ++gp;
            size = 1;
        }
    }

    int cn = n;
    int ans = 0;

    for (auto [key, val] : mp) {
        int mi = cn - (key - 1) * gp;

        if (k >= mi && (k - cn) % gp == 0) {
            ++ans;
        }

        cn -= key * val;
        gp -= val;
    }

    cout << ans << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        solve();
    }

    return 0;
}
```
