## 2. 题目大意

给定平面上 $n$ 个互不相同的点。若点对 $(i,j)$ 确定的直线两侧点数相同，则称它们组成一条分割线；落在直线上的点不计入任何一侧。求满足条件的点对数量。数据范围为 $1\le n\le100$，坐标绝对值不超过 $10^9$。

## 3. 思路

枚举每一对点 $A,B$，再枚举其余所有点 $P$，计算

$$
\overrightarrow{AB}\times\overrightarrow{AP}
=(x_B-x_A)(y_P-y_A)-(y_B-y_A)(x_P-x_A).
$$

结果大于 $0$ 表示 $P$ 在有向直线 $AB$ 左侧，小于 $0$ 表示在右侧，等于 $0$ 表示在直线上。若左右两侧点数相同，则当前点对计入答案。坐标差与叉积均使用 `long long`。

时间复杂度为 $O(n^3)$，额外空间复杂度为 $O(n)$。

## 4. Code

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point { long long x, y; };

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<Point> points(n);
    for (auto &[x, y] : points) cin >> x >> y;

    long long answer = 0;
    for (int i = 0; i < n; ++i) {
        for (int j = i + 1; j < n; ++j) {
            int left = 0, right = 0;
            long long abx = points[j].x - points[i].x;
            long long aby = points[j].y - points[i].y;
            for (int k = 0; k < n; ++k) {
                long long apx = points[k].x - points[i].x;
                long long apy = points[k].y - points[i].y;
                long long cross = abx * apy - aby * apx;
                if (cross > 0) ++left;
                else if (cross < 0) ++right;
            }
            if (left == right) ++answer;
        }
    }

    cout << answer << '\n';
    return 0;
}
```
