# 2240B AI Finds Nothing Here

## 1. 平台和题目

- 平台：Codeforces
- 题目：[2240B AI Finds Nothing Here](https://codeforces.com/problemset/problem/2240/B)
- 来源：2026-07-24-2307-算法-2240B-AI-Finds-Nothing-Here（capture_id：`2026-07-24-230756`）
- 每日总结：2026-07-24
- 算法类型：线性代数题目索引、组合计数题目索引、快速幂题目索引
- 相关知识：GF(2)线性方程组的解数
- 相关专题：滑动异或窗口方程的线性无关性、二进制快速幂

## 2. 题目大意

统计满足条件的 $n\times m$ 二进制矩阵：每个 $r\times c$ 连续子矩阵中所有元素的异或和都必须为 $0$。答案对 $998244353$ 取模。

## 3. 思路

把异或看成 $GF(2)$ 上的加法。矩阵的 $nm$ 个元素是二进制变量，每个 $r\times c$ 窗口给出一个齐次线性方程，共有

$$
(n-r+1)(m-c+1)
$$

个方程。

这些窗口方程线性无关。任取一个非空的窗口集合，先选择左上角行号最大的窗口，再在这些窗口中选择左上角列号最大的一个。它的右下角元素不会出现在其他被选窗口中，因此所有所选方程异或后该变量仍出现一次，不可能得到零方程。这个证明详见 滑动异或窗口方程的线性无关性。

所以方程组的秩就是窗口数量，自由变量数为

$$
nm-(n-r+1)(m-c+1).
$$

根据 GF(2)线性方程组的解数，合法矩阵数为

$$
2^{nm-(n-r+1)(m-c+1)}.
$$

指数可达 $10^{18}$，使用 二进制快速幂 取模计算。每个测试用例的时间复杂度为 $O(\log(nm))$，额外空间复杂度为 $O(1)$。

## 4. Code

以下代码已通过题目样例，并穷举核对了所有不超过 $3\times4$ 的矩阵尺寸和合法窗口尺寸；未据此声称平台 AC。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 998244353;

ll powerMod(ll base, ll exponent) {
    ll result = 1;
    while (exponent > 0) {
        if (exponent & 1LL) result = result * base % MOD;
        base = base * base % MOD;
        exponent >>= 1LL;
    }
    return result;
}

void solve() {
    ll n, m, r, c;
    cin >> n >> m >> r >> c;

    ll freeVariables = n * m - (n - r + 1) * (m - c + 1);
    cout << powerMod(2, freeVariables) << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) solve();
    return 0;
}
```
