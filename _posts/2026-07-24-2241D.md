# 2241D An Alternative Way

## 1. 平台和题目

- 平台：Codeforces
- 题目：[2241D An Alternative Way](https://codeforces.com/problemset/problem/2241/D)
- 来源：2026-07-24-2258-算法-2241D-An-Alternative-Way（capture_id：`2026-07-24-225842`）
- 每日总结：2026-07-24
- 算法类型：前缀和题目索引、贪心题目索引
- 相关专题：交替区间增减的前缀非负判定

## 2. 题目大意

给定两个长度为 $n$ 的数组 $a,b$。一次操作选择区间 $[l,r]$，从左端开始依次给元素加上 $+1,-1,+1,-1,\ldots$。判断能否通过若干次操作把 $a$ 变成 $b$。

## 3. 思路

令

$$
d_i=b_i-a_i,
\qquad
S_i=\sum_{j=1}^{i}d_j.
$$

一次区间操作在差值前缀和上的贡献只会是 $0$ 或 $1$，因此任何可达目标都必须满足所有 $S_i\ge0$。

这个条件也是充分的。任意区间操作都可以拆成若干个互不相交的长度为 $2$ 的操作，再加上至多一个长度为 $1$ 的操作，因此只需使用：

- $[i,i+1]$：给差值增加 $(+1,-1)$；
- $[i,i]$：给差值增加 $+1$。

对 $i<n$，使用 $S_i$ 次操作 $[i,i+1]$；最后使用 $S_n$ 次操作 $[n,n]$。位置 $i$ 得到的净变化为

$$
S_i-S_{i-1}=d_i
$$

（最后一个位置为 $S_n-S_{n-1}$），且所有操作次数都非负，所以构造合法。于是只需从左到右累加 $d_i$，一旦前缀和为负就输出 `NO`，否则输出 `YES`。详见 交替区间增减的前缀非负判定。

时间复杂度为 $O(n)$，额外空间复杂度为 $O(n)$。

## 4. Code

以下代码已通过题目样例；判定还对 $n\le4$、每个目标差值位于 $[-2,2]$ 的状态做了穷举可达性核对。未据此声称平台 AC。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

void solve() {
    int n;
    cin >> n;

    vector<ll> a(n), b(n);
    for (ll &x : a) cin >> x;
    for (ll &x : b) cin >> x;

    ll prefix = 0;
    for (int i = 0; i < n; ++i) {
        prefix += b[i] - a[i];
        if (prefix < 0) {
            cout << "NO\n";
            return;
        }
    }

    cout << "YES\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) solve();
    return 0;
}
```
