## 2. 题目大意

操作方式与 C 题相同：字符 $c$ 初始为 `2`，每次选择 $s$ 的一个位置与 $c$ 交换。给定 `1` 数量相同的两个 01 字符串 $s,t$，要求用最少的操作次数使 $s=t$，并输出一种最优方案。

## 3. 思路

仍把错位位置分成 $s_i=0,t_i=1$ 的数组 $a$ 和 $s_i=1,t_i=0$ 的数组 $b$，两者长度相同，设为 $q$。依次输出

$$
a_1,b_1,a_2,b_2,\ldots,a_q,b_q,a_1.
$$

第一次操作把 `2` 放到 $a_1$；之后按两类错位位置交替操作，使每个新访问的位置直接变成目标字符；最后再次操作 $a_1$，把其中的 `2` 换成 `1`。

所有 $2q$ 个错位位置都必须至少操作一次，而第一次操作必然把 `2` 放入字符串中的某个位置，这个位置还必须再操作一次，因此最少需要 $2q+1$ 次。上述方案恰好达到这个下界。若 $s=t$，答案为 $0$。

时间复杂度为 $O(n)$，额外空间复杂度为 $O(n)$。

## 4. Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    string s, t;
    cin >> n >> s >> t;

    vector<int> zeroToOne, oneToZero;
    for (int i = 0; i < n; ++i) {
        if (s[i] == t[i]) continue;
        if (s[i] == '0') zeroToOne.push_back(i + 1);
        else oneToZero.push_back(i + 1);
    }

    if (zeroToOne.empty()) {
        cout << 0 << '\n';
        return 0;
    }

    cout << 2 * zeroToOne.size() + 1 << '\n';
    for (int i = 0; i < static_cast<int>(zeroToOne.size()); ++i) {
        cout << zeroToOne[i] << '\n' << oneToZero[i] << '\n';
    }
    cout << zeroToOne[0] << '\n';
    return 0;
}
```
