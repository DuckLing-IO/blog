## 2. 题目大意

构造一个 $n$ 行 $m$ 列的 01 网格，使任意 $2\times2$ 区域都同时包含 `0` 和 `1`，并使所有值为 `1` 的方格按四连通计算后恰好形成 $k$ 个连通块。若无法构造，输出 `No`；否则输出 `Yes` 和任意一种合法网格。

## 3. 思路

若只有一行或一列，不存在 $2\times2$ 区域，只需间隔放置 $k$ 个 `1`。一般情况下，`1` 的连通块数量不超过网格最大独立集大小 $\lceil nm/2\rceil$；当 $n,m\ge2$ 时，$k=0$ 无解。

令

$$
limit=\left\lfloor\frac n2\right\rfloor\left\lfloor\frac m2\right\rfloor.
$$

先在 1-based 行列均为偶数的位置放 `1`。每个 $2\times2$ 中恰好有一个这种位置，因此已经保证每个 $2\times2$ 至少有一个 `1`，并得到 $limit$ 个互不相邻的连通块。

- 若 $k\ge limit$，再在 1-based 行列均为奇数的位置放置 $k-limit$ 个 `1`。这些位置只与原有 `1` 对角相邻，因此每个 `1` 仍是独立连通块。
- 若 $k<limit$，把偶数行、偶数列上的基础点看成一个 $\lfloor n/2\rfloor\times\lfloor m/2\rfloor$ 的点阵。选取其生成树中的 $limit-k$ 条边，并把每条边对应的中间格设为 `1`，每加入一条边就把两个连通块合并为一个。

第二种构造中，1-based 行列均为奇数的位置始终为 `0`；所以每个 $2\times2$ 始终至少有一个 `1` 和一个 `0`。

时间复杂度和空间复杂度均为 $O(nm)$。

## 4. Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, k;
    cin >> n >> m >> k;

    int maxComponents = (n * m + 1) / 2;
    if (k > maxComponents || (n >= 2 && m >= 2 && k == 0)) {
        cout << "No\n";
        return 0;
    }

    vector<string> grid(n, string(m, '0'));
    if (n == 1) {
        for (int j = 0; j < 2 * k; j += 2) grid[0][j] = '1';
    } else if (m == 1) {
        for (int i = 0; i < 2 * k; i += 2) grid[i][0] = '1';
    } else {
        int limit = (n / 2) * (m / 2);
        for (int i = 1; i < n; i += 2) {
            for (int j = 1; j < m; j += 2) grid[i][j] = '1';
        }

        if (k >= limit) {
            int need = k - limit;
            for (int i = 0; i < n && need > 0; i += 2) {
                for (int j = 0; j < m && need > 0; j += 2) {
                    grid[i][j] = '1';
                    --need;
                }
            }
        } else {
            int need = limit - k;
            for (int i = 1; i < n && need > 0; i += 2) {
                for (int j = 1; j + 2 < m && need > 0; j += 2) {
                    grid[i][j + 1] = '1';
                    --need;
                }
            }
            for (int i = 1; i + 2 < n && need > 0; i += 2) {
                grid[i + 1][1] = '1';
                --need;
            }
        }
    }

    cout << "Yes\n";
    for (const string &row : grid) cout << row << '\n';
    return 0;
}
```
