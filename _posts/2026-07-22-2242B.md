# 2242B Predominant Frequency Division

- 相关专题：双段划分的前缀最值判定

## 2. 题目大意

给定一个只包含 $1,2,3$ 的数组，需要将它划分为三个连续且非空的部分。左段中 $1$ 的数量不少于 $2$ 和 $3$ 的数量之和；中段中 $1$ 和 $2$ 的数量之和不少于 $3$ 的数量；右段没有内容限制。判断是否存在这样的划分。

## 3. 思路

分别为左段和中段定义贡献值：

- 判断左段时，元素 $1$ 的贡献为 $+1$，元素 $2,3$ 的贡献为 $-1$。设其前缀和为 $P_1$，则在位置 $x$ 后切开时，左段合法当且仅当 $P_1[x]\ge 0$。
- 判断中段时，元素 $1,2$ 的贡献为 $+1$，元素 $3$ 的贡献为 $-1$。设其前缀和为 $P_2$，则中段 $(x,y]$ 合法当且仅当 $P_2[y]-P_2[x]\ge 0$，即 $P_2[y]\ge P_2[x]$。

原思路会保存所有合法的左段终点，再分别向后扫描中段，最坏时间复杂度为 $O(n^2)$。实际上，对于当前枚举的中段终点 $y$，只需知道所有合法左段终点 $x<y$ 中最小的 $P_2[x]$。扫描时维护这个最小值；若当前 $P_2[y]$ 不小于它，就存在合法划分。这个降维过程见 双段划分的前缀最值判定。

每次先用此前保存的最小值判断当前 $y$，再把当前位置作为新的左段终点加入候选，从而保证中段非空。扫描只进行到 $n-1$，因此右段也一定非空。时间复杂度为 $O(n)$，额外空间复杂度为 $O(1)$。

## 4. Code

以下代码已通过题目样例，并与暴力算法对拍了所有长度为 $3$ 到 $10$ 的数组；未据此声称平台 AC。

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    cin >> n;

    vector<int> a(n);
    for (int &x : a) cin >> x;

    const int INF = 1e9;
    int prefixLeft = 0;
    int prefixMiddle = 0;
    int minMiddlePrefix = INF;

    for (int i = 0; i < n - 1; ++i) {
        prefixLeft += (a[i] == 1 ? 1 : -1);
        prefixMiddle += (a[i] == 3 ? -1 : 1);

        if (prefixMiddle >= minMiddlePrefix) {
            cout << "YES\n";
            return;
        }

        if (prefixLeft >= 0) {
            minMiddlePrefix = min(minMiddlePrefix, prefixMiddle);
        }
    }

    cout << "NO\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) solve();

    return 0;
}
```
