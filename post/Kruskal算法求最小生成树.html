Kruskal算法求最小生成树

2026-06-02 17:47 · ... 次浏览

Kruskal 的核心逻辑：“先对所有边按权重从小到大排个序，然后从小到大挑边，只要这条边不和已经选的边形成环，就将其加入到所选边。” 需要用一个并查集来维护。

Prim VS Kruskal：核心区别

两者的核心区别可以总结为：Prim 是“加点”，Kruskal 是“加边”。

特征 Prim 算法（堆优化） Kruskal 算法
核心思想 加点法。从一个初始点开始，不断把离当前树最近的点拉进来。 加边法。全局贪心，每次挑最短的边，只要不形成环就行。
数据结构 邻接表 + 优先队列（堆）+ 访问标记数组 边集数组 + 并查集
时间复杂度 $O(M \log N)$ $O(M \log M)$ （时间主要花在给边排序上）
适用场景 适合边很多的稠密图（$M \approx N^2$） 适合边较少的稀疏图（如本题，$N=5000, M=200000$）
代码难度 相对较难，需要处理邻接表和惰性删除 简单，只需一个结构体、一个 sort 和几行并查集

Kruskal 算法的三步走战略

  1. 存边并排序：把所有的边一股脑存进一个一维数组里，然后按照边权（长度）从小到大排序。
  2. 并查集初始化
  3. 贪心挑边：遍历排好序的边，看这条边连接的两个顶点 $u$ 和 $v$：
  4. 如果 $u$ 和 $v$ 没连通，就吸收这条边
  5. 如果 $u$ 和 $v$ 已经连通，说明收了这条边就会形成环，果断扔掉。
  6. 当我们成功收纳了 $N - 1$ 条边时，最小生成树形成。

例题

P1195 口袋的天空

题目背景

小杉坐在教室里，透过口袋一样的窗户看口袋一样的天空。

有很多云飘在那里，看起来很漂亮，小杉想摘下那样美的几朵云，做成棉花糖。

题目描述

给你云朵的个数 $N$，再给你 $M$ 个关系，表示哪些云朵可以连在一起。

现在小杉要把所有云朵连成 $K$ 个棉花糖，一个棉花糖最少要用掉一朵云，小杉想知道他怎么连，花费的代价最小。

输入格式

第一行有三个数 $N,M,K$。

接下来 $M$ 行每行三个数 $X,Y,L$，表示 $X$ 云和 $Y$ 云可以通过 $L$ 的代价连在一起。

输出格式

对每组数据输出一行，仅有一个整数，表示最小的代价。

如果怎么连都连不出 $K$ 个棉花糖，请输出 No Answer。

输入输出样例 #1

输入 #1

Text Only
3 1 2
1 2 1

输出 #1

Text Only
1

说明/提示

对于 $30\%$ 的数据，$1 \le N \le 100$，$1\le M \le 10^3$；

对于 $100\%$ 的数据，$1 \le N \le 10^3$，$1 \le M \le 10^4$，$1 \le K \le 10$，$1 \le X,Y \le N$，$0 \le L<10^4$。

解题思路

题目需要将 $N$ 个节点组成 $K$ 颗树，并要求所有树的边的权值之和最小。

期初将这 $N$ 个节点看成 $N$ 颗树，然后选取 $N-K$ 条边，形成 $N-K$ 条边的最小生成树，这样总共就 $K$ 颗树了，所得的边权之和即为题目所求。

情况特判：

  1. $K == N :$ 不用组合，直接输出 $0$。
  2. $K > N :$ 无法满足条件。
  3. 最后生成的最小生成树边树不够$N-K$。

代码

C++
#include<bits/stdc++.h>
using namespace std;
const int N = 1e4 + 5;

// 并查集部分
int f[1005];
//路径压缩/寻找父节点
int ff(int x){
    return x == f[x] ? x : f[x] = ff(f[x]);
}
//合并
bool mag(int x, int y){
    int rx = ff(x);
    int ry = ff(y);
    if(rx == ry) return false;

    f[rx] = ry;
    return true;
}

//生成树部分
struct e{
    int u, v, w;
} edges[N];

bool cmp(e a, e b){
    return a.w < b.w;
}

int n, m, k;

int main(){
    ios::sync_with_stdio(0);
    cin.tie(0); 

    cin >> n >> m >> k;

    for(int i = 1; i <= n; i++) f[i] = i;

    for(int i = 1; i <= m; i++){
        cin >> edges[i].u >> edges[i].v >> edges[i].w;
    }
    //所需的边数
    int ma = n - k;

    if(ma < 0){
        cout << "No Answer";
        return 0;
    } 

    if(n == k){
        cout << 0;
        return 0;
    }

    sort(edges + 1, edges + 1 + m, cmp);

    int ans = 0;
    int cnt = 0;

    for(auto& edge : edges){
        int u = edge.u;
        int v = edge.v;
        int w = edge.w;

        if(ff(u) == ff(v)) continue;
        mag(u, v);
        ans += w;
        cnt ++;
        //现有的生成树一旦满足条件就退出循环
        if(cnt == ma) break;
    }

    if(cnt != ma) cout << "No Answer";
    else cout << ans;

    return 0;
}
