[每日算法]P2040 打开所有的灯

2026-05-17 22:14 · ... 次浏览

题目背景

pmshz 在玩一个益 (ruo) 智 (zhi) 的小游戏，目的是打开九盏灯所有的灯，这样的游戏难倒了 pmshz……

题目描述

这个灯很奇 (fan) 怪 (ren)，点一下就会将这个灯和其周围四盏灯的开关状态全部改变。现在你的任务就是就是告诉 pmshz 要全部打开这些灯。

例如

Text Only
0  1  1
1  0  0
1  0  1
点一下最中间的灯 $(2,2)$ 就变成了

Text Only
0  0  1
0  1  1
1  1  1

再点一下左上角的灯 $(1,1)$ 就变成了

Text Only
1  1  1
1  1  1
1  1  1

达成目标。

最少需要 $2$ 步。

输入格式

$9$ 个数字，以 $3\times3$ 的格式输入，每两个数字中间只有一个空格，表示灯初始的开关状态。（$0$ 表示关，$1$ 表示开）

输出格式

一个整数，表示最少打开所有灯所需要的步数。

输入输出样例 #1

输入 #1

Text Only
0 1 1
1 0 0
1 0 1

输出 #1

Text Only
2

说明/提示

这个题水不水，就看你怎么考虑了……

题解

C++
#include<bits/stdc++.h>
using namespace std;

bool a[5][5];
bool b[4][4];
int ans = INT_MAX;

bool check(){
    for(int i = 1; i <= 3; i++)
        for(int j = 1; j <= 3; j++)
            if(a[i][j] == 0) return 0;
    return 1;
}
void f(int x, int y){
    a[x][y] = 1-a[x][y];
}
void f1(int x, int y){
    f(x,y);
    f(x,y-1); f(x,y+1);
    f(x-1,y); f(x+1,y);
}
void dfs(int idx, int s){
    if(idx > 9){
        if(check()){
            ans = min(ans,s);
        }
        return;
    }

    int x = (idx - 1) / 3 + 1;
    int y = idx % 3;
    if(y == 0) y = 3;
    // if(b[x][y] == 1){
    //     dfs(idx+1,s);
    // }else{
    //     b[x][y] = 1;
    //     f1(x,y);
    //     dfs(idx+1,s+1);
    //     b[x][y] = 0;
    //     dfs(idx+1,s+1);
    // }
    f1(x,y);
    dfs(idx+1,s+1);
    f1(x,y);
    dfs(idx+1,s);
    return;
}

int main(){

    for(int i = 1; i <= 3; i++)
        for(int j = 1; j <= 3; j++)
            cin >> a[i][j];
    dfs(1,0);
    cout << ans;
    return 0;
}
